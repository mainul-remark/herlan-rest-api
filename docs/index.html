Herlan REST API Documentation

Mobile application API for auth, account management, orders, loyalty program, product details, and payment placeholders.

Base URL Response Format Authentication Status Auth User Account Loyalty Coupons Orders Product Filters Products Recommendations Linked Products Payments Route Inventory

Base URL

Local development:

http://localhost/herlanlive3/wp-json/herlan/v1

Production:

https://YOUR_DOMAIN/wp-json/herlan/v1

Response Format

Successful responses use this wrapper:

{
  "success": true,
  "message": "",
  "data": {}
}

WordPress REST errors use this wrapper:

{
  "code": "herlan_error_code",
  "message": "Error message.",
  "data": {
    "status": 400
  }
}

Authentication

Protected endpoints require this header:

Authorization: Bearer USER_ID_BASE64.SECRET

Tokens are issued by login/register and expire after 30 days.

Protected endpoint auth errors: herlan_missing_token, herlan_invalid_token, herlan_expired_token.

Status

GET /status

Returns API status and site metadata. Public endpoint.

curl "http://localhost/herlanlive3/wp-json/herlan/v1/status"
{
  "success": true,
  "message": "",
  "data": {
    "api_version": "0.1.0",
    "site": "Herlan Live",
    "timezone": "Asia/Dhaka"
  }
}

Auth

POST /auth/login

Login with WordPress username/email and password. Returns a bearer token.

{
  "username": "customer@example.com",
  "password": "password123",
  "device_name": "iPhone 15"
}
{
  "success": true,
  "message": "",
  "data": {
    "token_type": "Bearer",
    "access_token": "MQ.example_token_secret",
    "expires_at": "2026-05-30T06:00:00+00:00",
    "user": {
      "id": 1,
      "name": "Customer Name",
      "first_name": "Customer",
      "last_name": "Name",
      "email": "customer@example.com",
      "username": "customer@example.com",
      "roles": ["customer"]
    }
  }
}

Errors: 401 herlan_invalid_credentials

POST /auth/register

Creates a WordPress user and returns a mobile token. WordPress registration must be enabled. Response shape is identical to login.

{
  "name": "Customer Name",
  "email": "customer@example.com",
  "password": "password123"
}

Errors: 403 herlan_registration_disabled   409 herlan_email_exists   422 herlan_invalid_email   422 herlan_weak_password

POST /auth/logout

Revokes the current bearer token.

curl -X POST "http://localhost/herlanlive3/wp-json/herlan/v1/auth/logout" \
  -H "Authorization: Bearer MQ.example_token_secret"

Account

PUT PATCH /user/account

Updates the authenticated user's profile. All fields are optional — only send what needs to change. Changing email or new_password requires current_password.

FieldTypeNotes
first_namestringNo password required
last_namestringNo password required
display_namestringNo password required
emailstringRequires current_password
current_passwordstringRequired when changing email or password
new_passwordstringMin 8 characters. Requires current_password

Update name

curl -X PATCH "http://localhost/herlanlive3/wp-json/herlan/v1/user/account" \
  -H "Authorization: Bearer MQ.example_token_secret" \
  -H "Content-Type: application/json" \
  -d "{\"first_name\":\"Jane\",\"last_name\":\"Doe\"}"

Change password

curl -X PATCH "http://localhost/herlanlive3/wp-json/herlan/v1/user/account" \
  -H "Authorization: Bearer MQ.example_token_secret" \
  -H "Content-Type: application/json" \
  -d "{\"current_password\":\"oldpass123\",\"new_password\":\"newpass456\"}"

Response

{
  "success": true,
  "message": "Account updated successfully.",
  "data": {
    "user": {
      "id": 1,
      "name": "Jane Doe",
      "first_name": "Jane",
      "last_name": "Doe",
      "email": "customer@example.com",
      "username": "customer@example.com",
      "roles": ["customer"]
    }
  }
}

Errors: 401 herlan_invalid_password   409 herlan_email_exists   422 herlan_password_required   422 herlan_invalid_email   422 herlan_weak_password

Loyalty

Returns the authenticated user's loyalty program summary — points, cash balance, level progress, and recent transactions. Requires the Herlan Loyalty plugin to be active and the user's billing phone number to be set. Results are cached per user for 5 minutes.

  "message": "",
  "data": {
    "customer": {
      "name": "Customer Name",
      "phone": "01712345678",

      "level": "Gold"

    "points": 1250,
    "available_cash": 125.50,
    "total_spent": 15000.00,
    "level": {
      "name": "Gold",
      "color": "#DDAE56",
      "progress_percent": 62.5,
      "next": "Platinum",
      "next_at": 20000,
      "retention": {
        "message": "Spend BDT 5,000 more to keep Gold level.",
        "target": 12000
      }
    },
    "next_expiring_cash": null,
    "transactions": {
      "purchase_orders": [],
      "redeem_orders": [],
      "cashes": []
    }
  }
}
FieldTypeNotes
pointsintegerUsable loyalty points
available_cashfloatRedeemable cash balance
total_spentfloatLifetime spend used for tier calculation
level.namestringCurrent tier name
level.colorstringTier accent color for the UI

Coupons

GET /user/coupons

Returns the authenticated user's coupons from the WooCommerce Smart Coupon plugin. Requires wt-smart-coupon-pro to be active.

ParameterTypeDefaultNotes
typestringavailableavailable, expired, or used
pageinteger1Page number
per_pageinteger10Max 50
orderbystringcreated_date:asccreated_date:asc, created_date:desc, amount:asc, amount:desc. Ignored for type=used
 
curl "http://localhost/herlanlive3/wp-json/herlan/v1/user/coupons" \
  -H "Authorization: Bearer MQ.example_token_secret"

curl "http://localhost/herlanlive3/wp-json/herlan/v1/user/coupons?type=expired&orderby=created_date:desc" \
  -H "Authorization: Bearer MQ.example_token_secret"

curl "http://localhost/herlanlive3/wp-json/herlan/v1/user/coupons?type=used&page=2" \
  -H "Authorization: Bearer MQ.example_token_secret"
{
  "success": true,
  "message": "",
  "data": {
    "coupons": [
      {
        "id": 4210,
        "code": "WELCOME10",
        "discount_type": "percent",
        "coupon_type": "Cart discount",
        "amount": 10.0,
        "coupon_amount": "10%",
        "description": "Welcome discount for new customers.",
        "free_shipping": false,
        "starts_at": null,
        "expires_at": "2026-12-31T23:59:59+00:00",
        "is_expired": false,
        "minimum_amount": "500",
        "maximum_amount": "",
        "usage_limit": 1,
        "usage_count": 0,
        "usage_limit_per_user": 1,

Pagination note: type=available and type=expired return has_more only — no total count, because the plugin applies live eligibility rules that make a total count query impractical. type=used additionally returns total and total_pages.

FieldTypeNotes
idintegerWooCommerce coupon post ID
codestringCoupon code to apply at checkout
discount_typestringRaw type: fixed_cart, percent, store_credit, wbte_sc_bogo, etc.
coupon_typestringHuman label: Cart discount, Product discount, Free shipping, Free products, Store credit, etc.
amountfloatRaw numeric discount amount
coupon_amountstringFormatted amount, e.g. ৳690 or 10%. Empty for free shipping / free product coupons
descriptionstringAdmin-defined coupon description
free_shippingbooleanWhether the coupon grants free shipping
starts_atstring|nullISO 8601 start date, or null if no start restriction
expires_atstring|nullISO 8601 expiry date, or null if the coupon never expires
is_expiredbooleantrue when expires_at is in the past
minimum_amountstringMinimum order subtotal required, empty if none
maximum_amountstringMaximum order subtotal allowed, empty if none
usage_limitintegerGlobal usage limit, 0 = unlimited
usage_countintegerTotal times the coupon has been used globally
usage_limit_per_userintegerPer-user usage limit, 0 = unlimited
used_by_current_userintegerTimes the authenticated user has used this coupon
individual_usebooleanCannot be combined with other coupons if true
email_restrictionsarrayRestricted email addresses, empty array if open to all

Product Filters

GET /products/filters

Returns mobile filter metadata for shop and taxonomy pages. Use taxonomy and term for category, brand, keyword, or attribute archive context. Results are cached for 10 minutes. Public endpoint.

curl "http://localhost/herlanlive3/wp-json/herlan/v1/products/filters"

curl "http://localhost/herlanlive3/wp-json/herlan/v1/products/filters?taxonomy=product_cat&term=makeup"

curl "http://localhost/herlanlive3/wp-json/herlan/v1/products/filters?taxonomy=brand&term=herlan"

The response includes sort_options, price_range, and filters. Filters include product_cat, brand, product_tag, keywords, and pa_* product attributes.

Products

Returns one published WooCommerce product for mobile product details. The product object is returned directly inside data. Public endpoint.

curl "http://localhost/herlanlive3/wp-json/herlan/v1/products/10119"

idintegerWooCommerce product ID
namestringProduct name

pricestringCurrent product price

linked_productsobjectWPC Linked Variation data for mobile swatches

Recommendations

The single product response includes the same four product sections used on the product detail page.

{
  "recommendations": {
    "you_may_like": {
      "title": "You May Like",
      "url": "http://localhost/herlanlive3/product-category/makeup/",
      "products": []
    },
    "more_from_this_brand": {
      "title": "More from this brand",
      "url": "http://localhost/herlanlive3/brand/herlan/",
      "products": []
    },
    "best_selling": {
      "title": "Best Selling",
      "url": "http://localhost/herlanlive3/shop/?orderby=sales",
      "products": []
    },
    "new_arrivals": {
      "title": "New Arrivals",
      "url": "http://localhost/herlanlive3/shop/?orderby=date",
      "products": []
    }
  }
}

Each product card includes id, name, permalink, prices, stock status, rating, brand, and main image.

Linked Products

linked_products is generated from the WPC Linked Variation plugin. It replaces frontend HTML such as .wpclv-attributes with mobile-ready JSON.

{
  "enabled": true,
  "link_id": 456,
  "source": "products",
  "attributes": [
    {
      "id": 1,
      "name": "pa_colors",
      "slug": "pa_colors",
      "label": "Colors",
      "display": "swatches",
      "current_terms": ["vintage-vibes"],
      "terms": [
        {
          "term_id": 999,
          "name": "Vintage Vibes",
          "slug": "vintage-vibes",
          "color": "#a8483d",
          "image": null,
          "active": true,
          "in_stock": true,
          "product": {
            "id": 10119,
            "name": "Herlan Cushion Matte Lipstick Vintage Vibes",
            "permalink": "http://localhost/herlanlive3/product/herlan-cushion-matte-lipstick-vintage-vibes/",
            "price": "690",
            "stock_status": "instock"
          }
        }
      ]
    }
  ]
}

For product 10119, the API returns pa_colors with terms like:

Vintage Vibes | active=true  | in_stock=true  | color=#a8483d | product.id=10119
Disco Diva    | active=false | in_stock=true  | color=#3e7155 | product.id=10150
Retro Rust    | active=false | in_stock=false | color=#803134 | product.id=10138

Payments

Payment endpoints are placeholders and require gateway integration before production use.

GET /payments/methods

Protected endpoint. Returns configured mobile payment methods.

POST /payments/create

Protected endpoint. Placeholder for creating a payment intent, session, or order payment request.
